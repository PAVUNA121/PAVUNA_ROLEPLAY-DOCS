# regras policia

{% stepper %}
{% step %}
## Após captura

Após capturado pela polícia, aceite o RP e as ordens do policial, evite exageros em sua história e em suas reações como detido/bandido.
{% endstep %}

{% step %}
## Roubo de viaturas

É proibido roubar qualquer viatura policial, a menos que esteja em uma ação. Nesse caso, poderá usufruir do veículo para fuga e abandoná-lo o mais rápido possível.
{% endstep %}

{% step %}
## Acesso às favelas, áreas de risco e zonas ilegais

Somente unidades especializadas e viaturas de comando poderão adentrar favelas, áreas de risco ou zonas ilegais a cada 30 minutos (tempo contado fora do jogo), sem necessidade de fundada suspeita.
{% endstep %}

{% step %}
## Restrições às unidades não especializadas

Unidades não especializadas estão proibidas, em qualquer hipótese, de ingressar em favelas, áreas de risco ou zonas ilegais sem fundada suspeita.
{% endstep %}

{% step %}
## Fundada suspeita

Fundada suspeita é caracterizada pelos seguintes fatores:

* Denúncias diretas;
* Roubo de veículos equipados com localizador ativo;
* Disparos de arma de fogo;
* Venda de drogas;
* Venda de armas;
* Publicações de apologia ao crime em redes sociais (ex Instagram);
* Chamados feitos via denúncias anônimas;
* Outras situações que configurem evidência clara de atividade criminosa.

Em caso de PINOTE/FUGA, a equipe POLICIAL responsável pela perseguição pode entrar na área de risco caso ele fuja para esse local.
{% endstep %}

{% step %}
## Apoio à especializada

Caso a ESPECIALIZADA pedir APOIO, a unidade que estiver mais próxima pode apoiar MESMO NÃO SENDO ESPECIALIZADA.
{% endstep %}

{% step %}
## Veículos na delegacia

É proibido roubar/furtar qualquer veículo na área da delegacia (safezone).
{% endstep %}

{% step %}
## COP BAIT

É proibido fazer COP BAIT (armar emboscada para polícia dentro das favelas).

Na rua, assim como a polícia pode pedir apoio de todas unidades que estão no QAP, o ilegal pode solicitar apoio via radio.
{% endstep %}

{% step %}
## Corrupção

É proibido qualquer RP que envolva corrupção, podendo acarretar em banimento permanente.
{% endstep %}

{% step %}
## DEEP WEB (TOR)

É proibido usar a DEEP WEB (TOR) para realizar emboscadas e prender integrantes do ilegal.

Os Policiais Federais podem usá-la somente para compras com intenção de gerar provas para investigações.
{% endstep %}
{% endstepper %}
