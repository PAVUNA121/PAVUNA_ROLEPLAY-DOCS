# 👮‍♂️ Abordagens Policiais | Vivência Carioca Docs

🚨 Só é permitido iniciar disparos imediatos em caso de abordagens Ostensivas/Agressivas. Caso esteja portando itens ilegais, o jogador tem três opções:

* Se entregar pacificamente.
* Iniciar um RP com a polícia, respeitando o bom senso.
* Iniciar fuga. Neste caso, o jogador deverá manter a fuga limpa. Caso corra para alguma área de risco e disparem contra os policiais, poderá ser considerado copbait e será passível de punição a facção.
