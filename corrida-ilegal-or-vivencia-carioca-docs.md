# 🏎 Corrida Ilegal | Vivência Carioca Docs

📌Esse tipo de ação é para sempre ser priorizado a FUGA LIMPA! É proibido o uso de armas de fogo em corridas ilegais, tanto para polícia, quanto para os corredores.

Ao término da corrida, caso a perseguição continue, fica proibido qualquer outra pessoa intervir na ação para ajudar o fugitivo.

RP de perseguição e fuga é prioridade para policiais e fugitivos.

💀 Corredores: Sem limite.

🚨 Policiais: Sem limite.
