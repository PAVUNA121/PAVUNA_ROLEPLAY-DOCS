# baques

{% stepper %}
{% step %}
## Baque restrito a facções rivais

Favelas **somente podem baquear** outras favelas que pertençam a **facções rivais**.
{% endstep %}

{% step %}
## Limite mensal de baques

Cada favela tem direito a **no máximo 4 baques por mês**.
{% endstep %}

{% step %}
## Intervalo obrigatório entre baques

Após baquear uma favela, é obrigatório aguardar **2 dias** para realizar um novo baque na **mesma favela**, visando a recuperação do lado oposto.
{% endstep %}

{% step %}
## Alianças permitidas

É permitida a **aliança de até 3 favelas** para realizar o baque contra uma favela de facção rival.
{% endstep %}

{% step %}
## Número mínimo de participantes

Para iniciar um baque, é necessário ter **no mínimo 5 integrantes** presentes.
{% endstep %}

{% step %}
## Devolução dos itens

Caso a favela que sofreu o baque **não devolva os itens em até 5 dias**, os itens do baú serão **entregues à favela que realizou o baque**.
{% endstep %}
{% endstepper %}
