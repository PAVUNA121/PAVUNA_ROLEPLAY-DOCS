# combat logging cl

## COMBAT LOGGING (CL)

Combat logging é deslogar durante qualquer ação/roleplay em que você esteja envolvido para não sofrer consequências de suas atitudes no roleplay.

Qualquer tipo de crash ou queda de conexão é obrigatório avisar imediatamente no canal reportar-crash, colocar o print sem cortes com data/hora do ocorrido.

Após resolver o problema de internet ou crash, é obrigatório retornar para continuar o roleplay.

**Punição CL:** 2 Advertências + 48h banimento + Limpeza inventário.

## DARK RP

É considerado DARK RP qualquer tipo de Roleplay que envolva:

* Qualquer tipo de preconceito (Racismo, Xenofobia, Homofobia, entre outros);
* Assédio;
* Suicídio;
* Aborto.

{% hint style="warning" %}
Podem haver outras situações que serão consideradas DARK RP dependendo da gravidade da situação, na dúvida, não diga, não faça!
{% endhint %}
