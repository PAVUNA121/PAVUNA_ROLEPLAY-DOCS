# 🏠 Regras Residências | Vivência Carioca Docs

Cada player pode ter apenas 3 casas nas comunidades (favelas).

As outras casas não tem limite por player.

Itens não devem ser transferidos / enviados para outros players dentro das casas, o item pode sumir e a PREFEITURA não irá fazer o reembolso.

Se nao fizer o pagamento das taxas na Imobiliária, você perderá a residência e os itens que estiverem no baú.
