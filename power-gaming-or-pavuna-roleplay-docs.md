# POWER GAMING | PAVUNA ROLEPLAYDocs

É a prática de abusar da mecânica ou bug do jogo para se beneficiar sobre outro adversário e/ou realizar ações impossíveis na vida real. Exemplos:

1. É proibido o uso de animações de maneira excessiva ou de forma abusiva.
2. É proibido subir em locais com veículos não compatíveis, subir montanhas ou até mesmo fazer saltos com veículos.
3. É proibido o uso de mods gráficos que alterem velocidade, dano ou qualquer tipo de física dentro do jogo.
4. É proibido circular com o veículo com mais de dois dos pneus danificados.
